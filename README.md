# -Greenwich-Registrars-Shareholder-Payout-Dashboard
An interactive Power BI dashboard analyzing shareholder dividend payouts for Greenwich Registrars.
This project demonstrates end-to-end data analytics from live MySQL integration to advanced DAX modeling, cross-filtering, and drill-through analysis built as part of a mentorship program.

# Highlights
1. Live MySQL Connection: Real-time refresh replacing manual CSV imports.

2. Advanced DAX Measures: Implemented RANKX, CALCULATE, and TOTALYTD for ranking, filtering, and cumulative trends.

3. Cross-Filtering Slicers: Interactive filters for State and Payment Status that update all visuals simultaneously.

4. Conditional Formatting: Visual cues for top shareholders and payout concentration.

5. Drill-Through Page: Detailed shareholder-level view showing declaration-by-declaration payment history.
 
# Key Insights
1. Corporate and institutional shareholders dominate payouts, accounting for 86% of ₦17.02M total net paid.

2. Payment activity peaked in May 2023 (₦8.8M) before stabilizing mid-year.

3. Unclaimed rate: 0.08%, reflecting strong payment efficiency and shareholder engagement.

4. Drill-through analysis shows corporate shareholders maintain consistent “Paid” statuses, while individuals display minor unclaimed balances.
